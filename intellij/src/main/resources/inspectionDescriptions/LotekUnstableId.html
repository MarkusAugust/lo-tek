Reports an id given to a LO-TEK builder function that is not the same on every render, or not unique on the page: from the loop index, a random value, the clock or a counter, or the same text in every row of a loop.

A morph recognises an element by its id. An id from the index follows the position, so what the user typed lands in the wrong row when the server inserts one; a new id on every render makes the morph replace the element along with focus and the text. Make the id from a key in the data, such as "case-${case.id}".
