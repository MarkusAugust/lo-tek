Reports a set from a LO-TEK builder function that is put on an element its part cannot be, such as label { lt(field.control) }: the control of a field belongs on the <input>, <textarea> or <select>. The wiring then points at something that is not the field.

It reports only what the code says for certain: the tag is read from the kotlinx.html call the lt(…) stands in, and only parts whose selector names a tag are judged. The quick fix moves the set when exactly one other lt(…) in the function stands in a tag the part allows.
